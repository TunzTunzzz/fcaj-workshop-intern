### Week 4 Objectives:

* Master various AWS storage types including S3, Glacier, AWS Backup, and Snow Family.
* Learn how to deploy a Static Website on S3 and combine content distribution configurations with CloudFront.
* Practice advanced S3 data management (Versioning, Multi-Region Replication) and the process of migrating VMs from on-premises to AWS.

### Week 4 Achievements:

* Successfully deployed an S3 Static Website integrated with CloudFront and securely configured public access permissions.
* Mastered and successfully practiced Bucket Versioning and Multi-Region Object Replication to ensure data safety.
* Understood the differences between AWS storage classes (Storage Class, Glacier) and how to optimize storage costs.
* Proficiently operated AWS Backup with S3 Buckets and understood the workflow of exporting/importing on-premises VMs to the cloud via AMI.
