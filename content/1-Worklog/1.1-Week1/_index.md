### Week 1 Objectives:

* Understand the fundamental concepts of cloud computing and the global infrastructure of AWS.
* Learn how to secure the root account with MFA and configure basic access control with Admin/User groups.
* Master cost management using AWS Budgets and understand the different tiers of AWS Support.

### Week 1 Achievements:

* Acquired a clear understanding of Cloud Computing and the pillars of AWS global infrastructure (Regions, Edge Locations, Availability Zones).
* Successfully configured Multi-Factor Authentication (MFA) to secure the root account.
* Created an Admin Group and IAM User to manage daily tasks securely without using the root account.
* Established AWS Budgets to monitor resource consumption and trigger alerts when costs exceed defined thresholds.
* Learned how to request and manage support cases under different AWS Support tiers.
